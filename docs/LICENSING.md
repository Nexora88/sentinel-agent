# MKAOS licensing notes

## Current license

The first-party MKAOS source in this repository is licensed under the **GNU General Public License v3.0 only (GPL-3.0-only)**. The complete license text is in the root `LICENSE` file. The independently packaged MCP server carries the same license text in its package directory.

GPLv3 is a strong copyleft license: when covered software is conveyed, recipients must receive the corresponding source under GPLv3 terms. Unlike AGPLv3, GPLv3 does not add AGPL's separate network-interaction source-offer condition merely because users interact with a modified program over a network.

## Transition from the earlier MIT notice

Earlier repository copies and releases that were already distributed under MIT remain subject to the permissions granted with those copies; a later license change cannot retroactively withdraw those permissions. This PR changes the license notice for the current first-party project going forward.

Before treating every historical file as relicensed, maintainers must confirm they hold the necessary rights for every contribution. If outside contributors submitted copyrightable code without an explicit inbound license or assignment, obtain appropriate permission or retain that contribution under its existing terms. Do not remove third-party notices. A repository-wide license change should not be represented as legally validated solely because the project owner selected a license.

## Third-party materials

Dependencies, model weights, datasets, voices, fonts, artwork, and bundled assets may have independent licenses and usage restrictions. GPLv3 on MKAOS does not override those terms. Keep a software bill of materials and preserve each component's license and attribution notices.

## Practical protection

- Keep dated public releases and signed tags where feasible.
- Preserve copyright and license notices.
- Record authorship and contribution permissions.
- When conveying covered binaries, provide the corresponding source as GPLv3 requires.
- Review trademarks separately; an open-source license does not grant unrestricted use of the MKAOS name or logo.
- Do not describe GPLv3 as preventing copying: it grants broad freedoms subject to copyleft obligations.

This document is project information, not legal advice. Have a qualified adult and an IP professional review the contributor history, third-party inventory, and relicensing decision before a public release or commercial licensing decision.
