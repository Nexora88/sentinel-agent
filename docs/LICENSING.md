# MKAOS licensing notes

## Current license

The first-party MKAOS source in this repository is marked **GNU Affero General Public License v3.0 only (AGPL-3.0-only)**. The complete, unmodified license text is in the root `LICENSE` file. The independent MCP distribution carries the same license text in its package directory.

AGPLv3 is based on GPLv3 and adds a network-interaction source-offer condition for users interacting remotely with a modified version of the covered program. It does not automatically require every unrelated service, independently written integration, or an entire company's codebase to be published. Whether separately deployed or combined components form one covered work is a fact-specific copyright question.

## Transition from the earlier MIT notice

Earlier repository copies and releases that were already distributed with an MIT license remain subject to the permissions granted with those copies. This repository's new first-party changes are marked AGPL-3.0-only. A license change cannot retroactively withdraw permissions already granted for an earlier copy.

Before treating every historical file as relicensed, the maintainers must confirm that they hold the necessary rights for every contribution. If outside contributors submitted copyrightable code without an explicit inbound license or assignment, obtain appropriate permission or retain that contribution under its existing terms. Do not remove third-party notices.

## Third-party materials

Dependencies, model weights, datasets, voices, fonts, artwork, and bundled assets may have independent licenses and usage restrictions. AGPL on MKAOS does not override those terms. Keep a software bill of materials and preserve each component's license and attribution notices.

## Practical protection

- Keep dated public releases and signed tags where feasible.
- Preserve copyright and license notices.
- Record authorship and contribution permissions.
- Publish source for covered modified network versions as required by AGPLv3.
- Review trademarks separately; an open-source license does not grant unrestricted use of the MKAOS name or logo.
- Do not describe AGPL as preventing copying: it grants broad freedoms subject to copyleft obligations.

This document is project information, not legal advice. Have a qualified adult and an IP professional review the contributor history, third-party inventory, and relicensing decision before a public release or commercial licensing decision.
